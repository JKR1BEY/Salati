# صلاتي — مواقيت الصلاة

تطبيق سطح مكتب عربي بسيط وأنيق لمواقيت الصلاة، مبني على فكرة تطبيق **Awqat Salaat** مع واجهة أسهل وأوضح.

![صلاتي](assets/icon.png)

## التنزيل

[**تحميل صلاتي 1.0.2 لـ Windows**](https://github.com/JKR1BEY/Salati/releases/latest) — مثبّت جاهز (Setup .exe).


## المزايا

- **العدّ التنازلي للصلاة القادمة** مع دائرة تقدّم متحركة.
- **مواقيت الصلوات الست** (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) بتوقيت مدينتك.
- **تحديد الموقع تلقائيًا** عبر الإنترنت عند أول تشغيل، أو البحث عن أي مدينة في العالم بالعربية أو الإنجليزية.
- **حساب تلقائي حسب البلد**: ديانت تركيا، أم القرى، الهيئة المصرية، كراتشي، رابطة العالم الإسلامي، وغيرها.
- **جدول شهري كامل** مع تمييز اليوم والجُمَع، وإمكانية **تصدير CSV**.
- **تنبيهات الأذان**: إشعارات Windows مع تنبيه ثابت قبل الصلاة بـ 5 دقائق.
- **أصوات أذان مدمجة**: أذان مكة، أذان المدينة، وأذان عبد الباسط عبد الصمد، مع خيار ملف أذان خاص (MP3 / WAV / M4A / OGG) أو «إشعار فقط» دون صوت.
- **أداة داخل شريط المهام** شفافة ومندمجة مع مظهر شريط المهام، تعرض الصلاة الحالية ووقتها، والصلاة القادمة مع عدّاد تنازلي حي. تظهر وتختفي وتتحرك مع الشريط نفسه (بما في ذلك الإخفاء التلقائي)، والضغط عليها يفتح بطاقة المواقيت المنبثقة.
- **يعمل في الخلفية** من شريط المهام، ويستطيع البدء مع Windows.
- **واجهتان**: داكنة وفاتحة، مع دعم كامل للعربية واتجاه RTL.
- **صيغة الوقت ١٢ ساعة افتراضيًا** (ص/م) في المواقيت والبطاقة المنبثقة وشريط المهام، مع إمكانية التبديل إلى ٢٤ ساعة من الإعدادات.
- **حساب المواقيت يعمل دون إنترنت** بعد حفظ المدينة.
- **تحديثات داخل التطبيق** من إصدارات GitHub: تحقق تلقائي عند بدء التشغيل (قابل للإيقاف)، أو تحقق يدوي، مع تنزيل وتثبيت مباشر على Windows.

## التشغيل أثناء التطوير

```powershell
npm.cmd install
npm.cmd start
```

> على Windows إذا كانت سكربتات PowerShell معطّلة، استخدم `npm.cmd` بدل `npm`.

## بناء نسخة مثبّتة

```powershell
npm.cmd run dist
```

ستجد المثبّت في المجلد `release` باسم `Salati-Setup-1.0.3.exe`.

لبناء نسخة محمولة بدون تثبيت:

```powershell
npm.cmd run dist:portable
```

## التحديثات داخل التطبيق

يعتمد التطبيق على **إصدارات GitHub** (Releases) لتوزيع التحديثات، عبر مكتبة `electron-updater` المتوافقة مع مثبّت NSIS:

- من **الإعدادات ← التطبيق** يمكنك تفعيل أو إيقاف **«التحقق التلقائي عند بدء التشغيل»** (مفعّل افتراضيًا).
- زر **«التحقق من التحديثات»** في بطاقة **التحديثات** يتيح التحقق يدويًا في أي وقت.
- عند توفر إصدار جديد تظهر ملاحظات الإصدار، ويمكنك **تنزيل التحديث** ثم **«إعادة التشغيل والتثبيت»**.
- عند الضغط على **«إعادة التشغيل والتثبيت»** يُغلق التطبيق ويُطبَّق التحديث **بشكل صامت** (بدون معالج تثبيت) ثم يُعاد تشغيل التطبيق تلقائيًا في الإصدار الجديد.
- في حال تعذّر التنزيل (انقطاع إنترنت، تجاوز حدّ GitHub، أو غياب ملفات التحديث) تظهر رسالة واضحة، ويمكن تنزيل المثبّت يدويًا من صفحة إصدارات GitHub.

> المثبّتات التي صدرت قبل إضافة نظام التحديث لا يمكنها التحديث ذاتيًا؛ يجب تثبيت نسخة أحدث يدويًا مرة واحدة.

## رفع إصدار جديد

1. حدّث رقم الإصدار في `package.json` (مثال: من `1.0.2` إلى `1.0.3`). يُفضّل اتباع [SemVer](https://semver.org/).
2. احذف محتوى مجلد `release` ثم أنشئ المثبّت:

   ```powershell
   npm.cmd run dist
   ```

   سيولّد electron-builder هذه الملفات في `release`:

   - `Salati-Setup-1.0.3.exe` — المثبّت.
   - `latest.yml` — بيانات الإصدار التي يقرأها التطبيق لاكتشاف التحديث.
   - `Salati-Setup-1.0.3.exe.blockmap` — ملف التحديث التفاضلي لتسريع التنزيل.

3. سجّل الدخول إلى GitHub عبر `gh auth login` (أو عيّن `GH_TOKEN`) ثم أنشئ الإصدار وارفع الملفات الثلاثة:

   ```powershell
   gh release create v1.0.3 release\Salati-Setup-1.0.3.exe release\latest.yml release\Salati-Setup-1.0.3.exe.blockmap --title "صلاتي 1.0.3" --generate-notes
   ```

   أو استخدم `npm.cmd run release` لنشر الإصدار تلقائيًا بعد المصادقة.

4. تأكد أن الإصدار **منشور** (ليس مسودة ولا تجريبي) وأن وسمه `v1.0.3` يطابق رقم الإصدار في `package.json`.

> لا يحتاج التطبيق إلى رمز وصول (token) للتحقق من التحديثات لأن المستودع عام، لكن نشر الإصدار يتطلب صلاحيات حسابك.

## اختبار التحديث من 1.0.0 إلى 1.0.1

1. ثبّت نسخة **1.0.0 تحتوي على نظام التحديث** محليًا من `release\Salati-Setup-1.0.0.exe` بعد بنائها بالخطوات أعلاه. (النسخة المنشورة سابقًا على GitHub لا تحتوي على النظام، لذا لن تتحقق ذاتيًا.)
2. غيّر الإصدار في `package.json` إلى `1.0.1`، ثم شغّل `npm.cmd run dist` وانشر `v1.0.1` بالملفات الثلاثة كما في القسم السابق.
3. افتح التطبيق المثبّت (1.0.0) وانتظر بضع ثوانٍ: سيظهر إشعار بتوفر الإصدار 1.0.1. أو اضغط **«التحقق من التحديثات»** فورًا.
4. راجع الحالات في بطاقة التحديثات: «جارٍ التحقق» ← «يتوفر إصدار جديد» مع الملاحظات ← «جارٍ التنزيل» مع نسبة التقدم ← «جاهز للتثبيت».
5. اضغط **«إعادة التشغيل والتثبيت»**؛ سيُغلق التطبيق ويُشغّل المثبّت، وبعد اكتماله سيفتح الإصدار 1.0.1.
6. من **الإعدادات ← التحديثات** تأكد أن «الإصدار الحالي» أصبح `1.0.1`، وجرّب تعطيل/تفعيل التحقق التلقائي وإعادة فتح التطبيق للتأكد من حفظ الإعداد.

## تثبيت التطبيق

1. شغّل الملف `release\Salati-Setup-1.0.3.exe` (مثبّت oneClick، per-user، بدون UAC).
2. يُثبَّت التطبيق في `%LOCALAPPDATA%\Programs\Salati`، ويُنشأ اختصار في قائمة ابدأ داخل مجلد **صلاتي** (قابل للبحث بـ «صلاتي» أو «Salati») واختصار على سطح المكتب.
3. افتح **صلاتي** من قائمة ابدأ أو سطح المكتب.

> المثبّت غير موقّع رقميًا، لذلك قد يعرض Windows SmartScreen تحذيرًا عند التشغيل لأول مرة.
> اضغط **More info** ثم **Run anyway**.

## البحث في Windows
- اضغط مفتاح Windows واكتب «صلاتي» أو «Salati» — يظهر اختصار التطبيق (داخل مجلد صلاتي) و/أو اختصار سطح المكتب.
- التحديثات (oneClick) تُحدِّث الاختصارات تلقائيًا دون ترك اختصارات معطوبة؛ المثبّت ينظّف الاختصارات القديمة (Salati.lnk) عند التثبيت.

## طريقة الاستخدام

1. عند أول تشغيل يحاول التطبيق تحديد موقعك تلقائيًا. إذا لم ينجح، اضغط شريط الموقع أعلى الصفحة (الذي يعرض المدينة والدولة) لفتح قسم **الموقع** والبحث عن مدينتك. يمكنك تفعيل **«طي قسم الموقع عند فتح الإعدادات»** من **الإعدادات ← التطبيق** لإخفاء القسم افتراضيًا.
2. تُختار طريقة الحساب تلقائيًا حسب بلد المدينة المحددة (مثل ديانت في تركيا، وأم القرى في السعودية).
3. من **الأذان والتنبيهات** فعّل التنبيهات، واختر أذان مكة أو المدينة أو عبد الباسط، أو أضف ملف أذان من جهازك.
4. زر **X** يغلق النافذة إلى شريط المهام حتى تستمر التنبيهات. لإغلاق التطبيق نهائيًا استخدم أيقونة شريط المهام ← **إغلاق صلاتي**.
5. تظهر **أداة الصلاة** داخل شريط المهام أسفل يسار الشاشة: العمود الأيمن للصلاة الحالية ووقتها، والأيسر للصلاة القادمة مع العدّاد التنازلي. اضغط عليها لفتح **بطاقة المواقيت** المنبثقة (اليوم الهجري والموقع وجدول الصلوات مع حالة كل صلاة)، وتُغلق بالضغط خارجها أو على `Esc` أو بالضغط على الأداة مجددًا. من رأس البطاقة يمكن فتح الإعدادات أو تحديث المواقيت.
6. من **الإعدادات ← التطبيق** يمكن تفعيل أو إخفاء أداة الصلاة في شريط المهام في أي وقت.
7. من **المواقيت** يمكنك التنقل بين الأشهر وتصدير الجدول إلى Excel.

## الخصوصية

- لا يُرسل التطبيق موقعك إلى أي جهة باستثناء:
  - خدمة تحديد الموقع عبر IP عند أول تشغيل (ipwho.is، مع بديل ipapi.co).
  - خدمة البحث عن المدن OpenStreetMap/Nominatim عند كتابة اسم مدينة.
- جميع حسابات المواقيت تتم محليًا على جهازك.
- لا توجد حسابات ولا تتبّع ولا إعلانات.

## ملاحظات

- المواقيت محسوبة فلكيًا، وقد تختلف بدقيقة أو دقيقتين عن مسجدك المحلي. تُختار طريقة الحساب تلقائيًا حسب بلد المدينة.
- الأصوات المدمجة تسجيلات أذان كاملة، ويمكنك إضافة أذانك المفضّل من الإعدادات عبر «ملف خاص».
- النظام مدعوم على Windows 10/11.

## بنية المشروع

```
main.js             عملية Electron الرئيسية: الحساب، التنبيهات، شريط المهام، أداة الشريط
preload.js          جسر آمن بين الواجهة والنظام
src/index.html      الواجهة العربية
src/styles.css      التصميم (داكن/فاتح)
src/app.js          منطق الواجهة والتفاعل
src/taskbar.html    أداة الصلاة داخل شريط المهام
src/taskbar.css     تصميم أداة الشريط
src/taskbar.js      تحديث الصلاة الحالية/القادمة والعدّاد كل ثانية
src/popup.html      بطاقة المواقيت المنبثقة من أداة شريط المهام
src/popup.css       تصميم البطاقة المنبثقة (داكن/فاتح)
src/popup.js        جدول الصلوات وحالاتها وأزرار الإعدادات والتحديث والمعلومات
src/cities.js       قائمة مدن جاهزة دون إنترنت
assets/             الأيقونات والخطوط
scripts/            مراقب حالة شريط المهام وتوليد الأيقونات
```
