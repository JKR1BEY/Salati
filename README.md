# صلاتي — مواقيت الصلاة

تطبيق سطح مكتب عربي بسيط وأنيق لمواقيت الصلاة، مبني على فكرة تطبيق **Awqat Salaat** مع واجهة أسهل وأوضح.

![صلاتي](assets/icon.png)

## التنزيل

[**تحميل صلاتي 1.0.0 لـ Windows**](https://github.com/JKR1BEY/Salati/releases/latest) — مثبّت جاهز (Setup .exe).


## المزايا

- **العدّ التنازلي للصلاة القادمة** مع دائرة تقدّم متحركة.
- **مواقيت الصلوات الست** (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) بتوقيت مدينتك.
- **تحديد الموقع تلقائيًا** عبر الإنترنت عند أول تشغيل، أو البحث عن أي مدينة في العالم بالعربية أو الإنجليزية.
- **طرق حساب متعددة**: ديانت تركيا، أم القرى، الهيئة المصرية، كراتشي، رابطة العالم الإسلامي، وغيرها، مع خيار مذهب العصر (شافعي/حنفي).
- **جدول شهري كامل** مع تمييز اليوم والجُمَع، وإمكانية **تصدير CSV**.
- **اتجاه القبلة** والمسافة إلى مكة المكرمة.
- **تنبيهات الأذان**: إشعارات Windows مع إمكانية تشغيل تنبيه قبل الصلاة بـ 5–30 دقيقة.
- **صوتان**: نغمة صلاة هادئة مدمجة، أو اختيار ملف أذان خاص (MP3 / WAV / M4A / OGG).
- **أداة مصغرة أسفل الشاشة** تعرض التاريخ والمدينة والمواقيت والعد التنازلي، مع الصلاة الحالية والصلاة القادمة، وتظهر عند إخفاء النافذة أو تصغيرها. اضغط عليها لفتح واجهة صلاتي.
- **يعمل في الخلفية** من شريط المهام، ويستطيع البدء مع Windows.
- **واجهتان**: داكنة وفاتحة، مع دعم كامل للعربية واتجاه RTL.
- **حساب المواقيت يعمل دون إنترنت** بعد حفظ المدينة.

## التشغيل أثناء التطوير

```powershell
npm.cmd install
npm.cmd start
```

> على Windows إذا كانت سكربتات PowerShell معطّلة، استخدم `npm.cmd` بدل `npm`.

## بناء نسخة مثبّتة

```powershell
npm.cmd run dist
```

ستجد المثبّت في المجلد `release` باسم `Salati-Setup-1.0.0.exe`.

لبناء نسخة محمولة بدون تثبيت:

```powershell
npm.cmd run dist:portable
```

## تثبيت التطبيق

1. شغّل الملف `release\Salati-Setup-1.0.0.exe`.
2. اتبع خطوات المثبّت، ثم افتح **صلاتي** من قائمة ابدأ أو من سطح المكتب.

> المثبّت غير موقّع رقميًا، لذلك قد يعرض Windows SmartScreen تحذيرًا عند التشغيل لأول مرة.
> اضغط **More info** ثم **Run anyway**. التطبيق لا يحتوي على إعلانات أو تتبّع، وكوده موجود كاملًا في هذا المجلد.

## طريقة الاستخدام

1. عند أول تشغيل يحاول التطبيق تحديد موقعك تلقائيًا. إذا لم ينجح، افتح **الإعدادات ← الموقع** وابحث عن مدينتك.
2. اختر **طريقة الحساب** المناسبة لبلدك (الافتراضي: تلقائي حسب البلد، ويستخدم ديانت في تركيا).
3. من **الأذان والتنبيهات** فعّل التنبيهات، واختر الصوت أو أضف ملف أذان من جهازك.
4. زر **X** يغلق النافذة إلى شريط المهام حتى تستمر التنبيهات. لإغلاق التطبيق نهائيًا استخدم أيقونة شريط المهام ← **إغلاق صلاتي**.
5. عند تصغير النافذة أو إخفائها تظهر **الأداة المصغرة** أسفل يسار الشاشة فوق شريط المهام. اضغط على الأداة لفتح صلاتي، أو استخدم زر الإعدادات داخلها، أو أخفها بزر **X**.
6. من **الإعدادات ← التطبيق** يمكن تفعيل أو إخفاء الأداة المصغرة في أي وقت.
7. من **المواقيت** يمكنك التنقل بين الأشهر وتصدير الجدول إلى Excel.

## الخصوصية

- لا يُرسل التطبيق موقعك إلى أي جهة باستثناء:
  - خدمة تحديد الموقع عبر IP عند أول تشغيل (ipwho.is، مع بديل ipapi.co).
  - خدمة البحث عن المدن OpenStreetMap/Nominatim عند كتابة اسم مدينة.
- جميع حسابات المواقيت تتم محليًا على جهازك.
- لا توجد حسابات ولا تتبّع ولا إعلانات.

## ملاحظات

- المواقيت محسوبة فلكيًا، وقد تختلف بدقيقة أو دقيقتين عن مسجدك المحلي. استخدم طريقة الحساب المعتمدة في بلدك.
- النغمة المدمجة نغمة تنبيه وليست أذانًا مسجّلًا. يمكنك إضافة أذانك المفضّل من الإعدادات.
- النظام مدعوم على Windows 10/11.

src/styles.css     التصميم (داكن/فاتح)
src/app.js         منطق الواجهة والتفاعل
src/widget.html    الأداة المصغرة أسفل الشاشة
src/widget.css     تصميم الأداة المصغرة
src/widget.js      تحديث المواقيت والعد التنازلي في الأداة
src/cities.js      قائمة مدن جاهزة دون إنترنت
assets/            الأيقونات والخطوط
scripts/           توليد الأيقونات
